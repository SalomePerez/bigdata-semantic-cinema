Modelo RDF

Uso de Tripletas (Sujeto-Predicado-Objeto) bajo el namespace http://www.cinecolombia.com/peliculas#. Cada película es un recurso único con propiedades explícitas.

SELECT (COUNT(?p) AS ?cant) WHERE { ?p cine:titulo ?t }
